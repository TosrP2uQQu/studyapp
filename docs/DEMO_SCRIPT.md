# DEMO_SCRIPT.md — 3-minute walkthrough

Account: register fresh (or `demo/demo1234` after `npm run seed`).

## 0:00 — Today (the home)
Open `/today`: plan line (due + est. minutes), goal ring,
**Start today's plan**. Note the Resume list if you left mid-deck.

## 0:30 — Study (rate + history + tutor)
Flip a card, rate Hard/OK/Easy (keys 1/2/3). Point at the history
strip: dots with tooltips (date, mode, interval change). Press `T`:
the Tutor opens with this card as context. `?` shows all shortcuts.

## 1:15 — Rating history
Open the recall sheet: last-rating chips, H/O/E counts, trend,
difficulty, leech flags. Flip a filter chip (Stubborn), toggle
Hardest first. Open a leech: Split it, or follow to the tutor.

## 1:50 — Import + Explore
Deck editor → paste 3 lines (`front, back`) → Parse → summary
("3 cards, 0 skipped"). **Structure with AI** (needs key) for
messy notes. Explore → add a starter deck in one tap.

## 2:20 — Tutor + videos
Tutor → Practice mode → streaming answer → Stop. Videos tab:
query links open YouTube results (no scraping); attach a URL for
a click-to-load player. Explore tab for the interactive diagram.

## 2:45 — Done for today
Finish the plan: summary grid with chips + seconds, **Re-drill
the Hard ones** (cram, scheduling untouched). Today shows
Done-for-today: XP, streak, sleep tip, forecast. Settings →
Wellbeing for every off-switch.
